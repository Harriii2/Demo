<h3> Book Scraper Demo (Testing) </h3>

This project is a simple demo created for testing web scraping using Python.
It fetches book information such as title, price, stock availability, rating, and image URL from the website <a href= "https://books.toscrape.com/">Books to Scrape</a>.
The script is built using the requests and parsel libraries and It’s mainly intended for testing and learning basic scraping techniques.<br>

<h3> Features </h3>
- Scrapes multiple pages of book listings<br>
- Extracts useful details (title, price, rating, etc.)<br>
- Prints results in a readable format<br>
